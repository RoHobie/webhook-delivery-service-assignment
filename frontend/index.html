Testing Local Webhook Deliveries

            
How to test webhook deliveries with real HTTP 200 or 500 responses.

          

        


        

          

            When registering an endpoint, the service makes real HTTP calls to the URL you provide. To demonstrate successful deliveries, failures, retries, and dead-lettering:
          


          
Option A: Test Connectivity using Self-Test Endpoint

          

            Register any target URL (e.g. http://localhost:8080/actuator/health or https://httpbin.org/post), then click the Test Ping button on the Endpoints panel to test synchronous reachability.
          


          
Option B: Use Online Mock Receiver (webhook.site)

          
    
            
  1. Go to webhook.site in a new tab.
    2. 
            
  2. Copy your unique webhook URL.
    3. 
            
  3. Register that URL in the Endpoints tab.
    4. 
            
  4. Publish an event in the Send Event tab.
    5. 
            
  5. Watch real-time delivery logs in the Deliveries tab change to DELIVERED, and inspect headers (X-Webhook-Signature) on webhook.site!
